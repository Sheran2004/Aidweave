# Contributing to Aidweave

Thanks for wanting to help. This project aims to make practical, community-led support easier to find while protecting the people who ask for it.

## Before opening a change

- Keep requesters' safety, privacy and dignity central.
- Never add real people's personal information to examples, screenshots, tests or seed data.
- Keep the experience usable with a keyboard and on narrow screens.
- Explain the problem your change solves and how a maintainer can review it.
- For larger changes, open an issue first so the community can discuss the approach.

## Local setup

1. Install Python 3.
2. Run `python server.py` from the project directory.
3. Open `http://localhost:8000`.

The application uses only Python's standard library and SQLite. The database file is local and ignored by Git.

## Reporting a security concern

Please do not publish details of a security vulnerability in a public issue. Until a private security contact is established, do not submit real user data or expose a deployment to the public internet. This is a prototype and has not completed a production security review.
